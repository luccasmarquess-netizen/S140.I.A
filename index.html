Guia de Uso — Cronos

🚀 Primeiro acesso
  1. Faça login com sua conta Google
  2. Na tela de boas-vindas, escolha entre nova congregação ou importar dados existentes
  3. Vá em Pessoas e cadastre os membros (ou importe um .txt)
  4. Em Configurações, defina o nome da congregação e horário de início
  5. Clique em 📖 Importar apostila para buscar os temas do jw.org automaticamente
📅 Programação (S-140)
  • Use ✨ Sugerir designações para preencher automaticamente seguindo as regras de rotatividade
  • Clique em qualquer campo de designação para ver a lista filtrada por elegibilidade
  • O picker mostra novo = nunca designado este mês, 3× = 3 designações (atenção)
  • ⚠ no nome = conflito (mesma seção na mesma semana)
  • Use ⏱ Recalcular horários após configurar o horário de início
  • Use 📦 Arquivar mês ao finalizar — salva no histórico e limpa para o próximo mês
👥 Pessoas e habilitações
  • Cada pessoa tem uma função (ancião, servo, publicador, publicadora) que define onde pode aparecer
  • Habilitações: clique nas partes que a pessoa pode fazer. Vazio = pode tudo
  • Publicadoras só veem a habilitação Faça Seu Melhor
  • Semanas indisponíveis: marque S1-S5 quando a pessoa estiver ausente
  • Importe via .txt: uma pessoa por linha, formato Nome, função
⚙ Mecânicas e Limpeza
  • Na aba Mecânicas: designe Áudio, Vídeo, Microfone, Palco e Indicador por semana, para Meio de Semana e Fim de Semana separadamente
  • Marque Mecânicas (áudio/vídeo) na ficha da pessoa para ela aparecer nesta aba
  • Na aba Limpeza: cadastre grupos fixos com os membros e use 🔄 Rotacionar para distribuir automaticamente
  • Clique em 🖨 Imprimir em Mecânicas para gerar a folha no formato padrão
🏘 Campo
  • Configure os dias recorrentes e locais em ⚙ Configurar
  • Selecione o mês — a tabela mostra todos os dias daquele mês automaticamente
  • Use ✨ Sugerir dirigentes para distribuir automaticamente
  • Imprima a Lista de Campo no formato padrão com 🖨
💾 Dados e backup
  • Os dados são salvos automaticamente no navegador a cada alteração
  • Use 💾 Exportar regularmente para fazer backup (.json)
  • Para usar em outro dispositivo: Exportar → enviar o arquivo → Importar no novo dispositivo
  • Use 📦 Arquivar mês ao fechar o mês — o histórico mantém os últimos 2 meses para a sugestão automática considerar
  • Cada congregação usa o mesmo site com seus próprios dados no dispositivo
🎉 Eventos especiais
  • Em Configurações → Eventos especiais, cadastre Assembleias, Congressos e Visitas do Superintendente
  • Sem reunião: cancela a semana inteira — aparece banner na programação
  • Visita do Superintendente: programação normal, EBC substituído pelo discurso. Adicione o tema do discurso no banner da semana
